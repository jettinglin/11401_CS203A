## 整體架構說明

### 筆記格式
每一份題目的解析都會包含：
* **整體架構**：程式的進入點跟大方向。
* **核心概念**：這題到底在考什麼。
* **實作說明**：程式碼每一段是在幹嘛（口語化解釋）。
* **優缺點分析**：這招好在哪？哪裡可能會有問題？
* **複雜度分析**：時間跟空間的消耗狀況。
